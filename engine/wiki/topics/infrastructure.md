# Infrastructure & CI

## Purpose
[coverage: high — 4 sources]
Cross-platform CI for candle workspace + Python wheel publishing + secret scanning + local lint hooks. Five GitHub Actions workflows (`.github/workflows/`): `rust-ci.yml`, `ci_cuda.yaml`, `python.yml`, `maturin.yml`, `trufflehog.yml`. Local: `Makefile` (build/test/clean helpers) + `.pre-commit-config.yaml` (rust fmt + clippy). `.cargo/config.toml` exists but is removed on macOS CI (ring-crate workaround, rust-ci.yml:13-15).

## Architecture
[coverage: high — 4 sources]
**`rust-ci.yml`** — `cargo check --workspace` on matrix `os: [ubuntu-latest, ubuntu-24.04, windows-latest, macOS-latest, ubuntu-24.04-arm]` (rust-ci.yml:10-12). macOS job adds `--features metal` (rust-ci.yml:21-22). Python 3.13 setup + `dtolnay/rust-toolchain@stable`. Triggers: push to `main`, pull_request.

**`ci_cuda.yaml`** — CUDA CI on self-hosted AWS g5-4xlarge, container `nvidia/cuda:13.0.2-cudnn-devel-ubuntu24.04`. Concurrency group cancels superseded runs. Only runs for same-repo PRs (`head.repo.full_name == base.repo.full_name`). Triggers: `workflow_dispatch`, pull_request. Permissions: contents+packages write.

**`python.yml`** ("PyO3-CI") — `candle-pyo3` build+test on `ubuntu-latest` only (matrix). Path-filtered to `candle-pyo3/**` on PRs and push to main.

**`maturin.yml`** ("PyO3-Wheels") — builds/publishes wheels on push to main, tags (`'*'`), path-filtered `candle-pyo3/**`. `PROTOC_VERSION='25.0'` env (needed for ONNX/prost builds, see candle-core topic).

**`trufflehog.yml`** — secret scanning (standard trufflehog action).

**`.pre-commit-config.yaml`** — `Narsil/pre-commit-rust` repo, `rev: 2eed6366...`, hooks: `fmt` + `clippy --tests --examples -- -Dwarnings`.

**`Makefile`** — `clean-ptx` (delete `target/**/*.ptx`, clobber `candle-kernels/src/lib.rs`, touch build.rs files), `clean` (`cargo clean`), `test` (`cargo test`), `all: test`.

## Key Decisions
[coverage: medium — 3 sources]
- **Matrix covers 5 OS targets** (rust-ci.yml:10-12) including `ubuntu-24.04-arm` for ARM Linux — broad coverage.
- **macOS Metal feature in CI** (rust-ci.yml:21-22): only macOS job enables `--features metal`, matching the Metal-kernel dependency path used by `qwen35-batch`.
- **CUDA CI gated to same-repo PRs** (ci_cuda.yaml:13) — AWS GPU runners are expensive; fork PRs skip CUDA.
- **Pre-commit clippy with `-Dwarnings`** (.pre-commit-config.yaml) — zero-tolerance lint policy.
- **Makefile `clean-ptx` is destructive** — clobbers `candle-kernels/src/lib.rs` (regenerated by build.rs), only for kernel rebuilds.

## Gotchas
[coverage: medium — 3 sources]
- **`qwen35-batch` real-model tests don't run in CI** — no workflow passes `--features real-model`; the `real_qwen35_batch`/`real_qwen35_quality` tests (`#[ignore]` + require GGUF) only run manually. CI only builds the mock path.
- **`.cargo/config.toml` deleted on macOS CI** (rust-ci.yml:13-15) — if you rely on local `.cargo/config.toml` settings, they won't apply in macOS CI.
- **CUDA container is CUDA 13.0.2 + cuDNN devel** — local CUDA must match `cudarc 0.19.1` workspace pin or builds fail.
- **Pre-commit `rev` is a pinned Narsil fork** (not the mainstream pre-commit-hooks) — `pre-commit install` fetches that specific commit.
- **trufflehog runs on all PRs** — accidental secret commits will fail CI.
